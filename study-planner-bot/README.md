# Study Planner Bot

Telegram-бот для студентов.

Функции:
- импорт расписания через .ics;
- просмотр расписания;
- задачи и дедлайны;
- поиск свободного времени;
- уведомления.

## Запуск

### 1. Установка зависимостей

pip install -r requirements.txt

### 2. Настройка .env

Указать BOT_TOKEN.

### 3. Запуск

python -m app.bot

.\venv\Scripts\activate
