# Стратегия тестирования

## Что нужно проверить

- запуск бота;
- загрузку `.ics`;
- кнопку **сегодня**;
- кнопку **неделя**;
- кнопку **свободное время**;
- отображение кабинета;
- добавление задач;
- просмотр задач.

## Unit-тесты `.ics`

### Кабинет из `LOCATION`

```ics
LOCATION:Online
```

Ожидание:

```python
location == "Online"
```

### Кабинет из `DESCRIPTION`

```ics
DESCRIPTION:Практическое занятие\nАудитория: Г-418
```

Ожидание:

```python
location == "Г-418"
```

### Перенос строки

```ics
DESCRIPTION:Практическое занятие\nАудитория:
  Г-418
```

Ожидание:

```python
location == "Г-418"
```

### Нет кабинета

Ожидание:

```python
location == "Не указано"
```

## Unit-тест свободного времени

Пары:

```text
13:45 - 15:20
15:50 - 17:25
17:35 - 19:10
```

Ожидание:

```text
15:20 - 15:50
17:25 - 17:35
```

## Ручные тесты

| Действие | Ожидание |
|---|---|
| `/start` | меню |
| отправить `.ics` | успешная загрузка |
| `сегодня` | пары на сегодня |
| `неделя` | пары на неделю |
| `свободное время` | окна между парами |
| `добавить задачу` | запрос текста |
| отправить задачу | сохранение |
| `мои задачи` | список задач |

## Проверка кнопок

Должны работать:

- `сегодня`;
- `Сегодня`;
- `📅 Сегодня`;
- `неделя`;
- `📆 Неделя`;
- `свободное время`;
- `🕓 Свободное время`.

## Критерий готовности

MVP готов, если бот запускается, кнопки работают, кабинет отображается, задачи сохраняются, а ошибки не ломают приложение.
