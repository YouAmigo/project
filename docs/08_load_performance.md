# Нагрузка и производительность

## Тип нагрузки

Study Planner Bot — бот с небольшой нагрузкой.

| Операция | Тип нагрузки |
|---|---|
| Загрузка `.ics` | CPU + диск |
| Сегодня | чтение расписания |
| Неделя | фильтрация событий |
| Свободное время | сортировка и расчёт |
| Добавить задачу | запись |
| Мои задачи | чтение |

## MVP

Для MVP допустимо:

- читать `.ics` при каждом запросе;
- хранить задачи в JSON;
- не использовать кэш;
- не использовать БД.

## Проблемы при росте

| Проблема | Причина |
|---|---|
| Данные смешиваются | общие файлы |
| Расписание медленнее | `.ics` парсится каждый раз |
| JSON может повреждаться | одновременная запись |
| Сложно удалять задачи | нет нормальных ID |
| Нет истории | файлы перезаписываются |

## Решение

Перейти на SQLite:

- парсить `.ics` один раз при загрузке;
- хранить пары в `schedule_items`;
- хранить задачи в `tasks`;
- разделять пользователей через `user_id`.

## Оценка

| Операция | MVP | SQLite |
|---|---:|---:|
| Сегодня | до 2 сек | до 0.5 сек |
| Неделя | до 2 сек | до 0.5 сек |
| Свободное время | до 1 сек | до 0.5 сек |
| Добавить задачу | до 1 сек | до 0.5 сек |

## Рекомендуемые лимиты

| Ограничение | Значение |
|---|---:|
| `.ics` файл | до 5 MB |
| задача | до 500 символов |
| задач в MVP | до 100 |
| минимальное окно | 5 минут |
