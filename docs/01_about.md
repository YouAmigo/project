# Study Planner Bot

## О проекте

**Study Planner Bot** — Telegram-бот для студента, который помогает работать с расписанием, задачами и свободным временем.

Текущий MVP уже ориентирован на простую схему:

- пользователь загружает файл `.ics`;
- бот сохраняет расписание в `app/data`;
- кнопка **сегодня** показывает пары на текущий день;
- кнопка **неделя** показывает пары на ближайшие 7 дней;
- кнопка **свободное время** ищет окна между парами;
- кнопка **добавить задачу** сохраняет заметку;
- кнопка **мои задачи** показывает задачи из JSON.

## Цель

Сделать удобного Telegram-помощника, который отвечает на главные вопросы студента:

| Вопрос | Ответ бота |
|---|---|
| Какие пары сегодня? | Расписание на текущую дату |
| Где проходит пара? | Кабинет, корпус, спортзал или Online |
| Что будет на неделе? | Расписание на 7 дней |
| Когда есть окно? | Свободное время между парами |
| Какие задачи есть? | Список сохранённых задач |

## Важная особенность `.ics`

В разных `.ics` файлах место занятия хранится по-разному.

Иногда так:

```ics
LOCATION:Online
```

А иногда так:

```ics
DESCRIPTION:Практическое занятие\nАудитория: Г-418
```

Поэтому парсер должен искать место в таком порядке:

1. `LOCATION`;
2. `Аудитория:` внутри `DESCRIPTION`;
3. если ничего нет — `Не указано`.

## Текущие функции MVP

| Функция | Статус |
|---|---|
| Загрузка `.ics` | MVP |
| Сохранение расписания в файл | MVP |
| Расписание на сегодня | MVP |
| Расписание на неделю | MVP |
| Свободное время | MVP |
| Задачи в JSON | MVP |
| Кабинет из `LOCATION` и `DESCRIPTION` | нужно поддерживать обязательно |
| Разделение пользователей | следующий этап |
| SQLite | следующий этап |
| Напоминания | следующий этап |

## Что не входит в MVP

- веб-сайт;
- авторизация через браузер;
- Google Calendar;
- роли администратора;
- сложная аналитика;
- платёжные функции.

## Следующий этап

Главное улучшение проекта — перейти от общих файлов к данным конкретного пользователя:

```text
Telegram user → свои задачи → своё расписание
```

Для этого нужно подключить SQLite и добавить таблицы:

- `users`;
- `schedule_items`;
- `tasks`;
- `user_settings`.
