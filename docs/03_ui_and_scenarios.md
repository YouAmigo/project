# UI и пользовательские сценарии

## Главное меню

Рекомендуемые кнопки:

```text
сегодня
неделя
свободное время
добавить задачу
мои задачи
загрузить .ics
```

Обработчики лучше делать мягкими, чтобы они работали с эмодзи и разным регистром:

```python
"сегодня" in message.text.lower()
"недел" in message.text.lower()
"свобод" in message.text.lower()
```

## Загрузка `.ics`

Сценарий:

1. пользователь отправляет файл;
2. бот проверяет расширение;
3. бот сохраняет файл;
4. бот отвечает: `Расписание успешно загружено`.

Ошибка:

```text
Нужно загрузить файл .ics
```

## Добавление задачи

Сценарий:

1. пользователь нажимает **добавить задачу**;
2. бот просит ввести текст;
3. пользователь отправляет текст;
4. бот сохраняет задачу;
5. бот отвечает: `Задача добавлена`.

## Типовые ошибки

| Проблема | Причина | Решение |
|---|---|---|
| Кнопка не работает | текст кнопки не совпал | проверять через `in` |
| Место `Не указано` | нет `LOCATION` | искать `Аудитория:` в `DESCRIPTION` |
| Неделя пустая | нет событий на 7 дней | проверить даты |
| Задачи не сохраняются | нет `app/data` | создавать папку автоматически |
